# 🎬 Netflix Data Analysis

## 📌 Project Overview

This project focuses on **analyzing and exploring the Netflix dataset** to understand the content available on the platform.

The analysis includes **data cleaning, data preprocessing, exploratory data analysis (EDA), and data visualization** to identify trends and patterns in Netflix movies and TV shows.

---

## 🎯 Objectives

- Clean and preprocess the Netflix dataset
- Analyze Movies vs. TV Shows
- Identify the most common genres
- Analyze content by country
- Explore the distribution of release years
- Analyze content ratings
- Identify trends in Netflix content over time
- Visualize important insights using charts and graphs

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook**

---

## 📂 Dataset

The dataset contains information about Netflix titles, including:

- `show_id`
- `type`
- `title`
- `director`
- `cast`
- `country`
- `date_added`
- `release_year`
- `rating`
- `duration`
- `listed_in`
- `description`

---

## 🔍 Data Analysis Process

### 1. Data Cleaning

The dataset was checked and cleaned by:

- Handling missing values
- Removing duplicate records
- Converting columns into appropriate data types
- Cleaning inconsistent values
- Extracting useful information from existing columns

### 2. Exploratory Data Analysis

The project explores questions such as:

- How many Movies and TV Shows are available?
- Which type of content is more common?
- Which countries produce the most Netflix content?
- What are the most popular genres?
- How has Netflix content changed over the years?
- Which ratings are most common?
- What is the distribution of movie durations?

### 3. Data Visualization

Different charts were created to communicate insights, including:

- Bar Charts
- Count Plots
- Pie Charts
- Histograms
- Line Charts
- Distribution Plots

---

## 📊 Key Insights

The analysis helps understand:

- The distribution of Movies and TV Shows on Netflix
- Major content-producing countries
- Popular genres and categories
- Netflix's content growth over time
- Common content ratings
- Movie duration patterns

> **Note:** Exact findings depend on the version of the Netflix dataset used in the notebook.
